# Drone Mission Planner v1.2.0 release report

Release date: 2026-09-15

## Scope

v1.2.0 completes the planned "real mission planning foundation" mainline from F0 through F7:

- F0: reproducible baseline, semantic decisions and fixture coverage.
- F1: one authoritative 3D waypoint route representation.
- F2: cumulative scheduling, dependencies, waiting, energy ledger, simulation timeline and Gantt readout.
- F3: global multi-vehicle optimisation, hard-constraint verification, coverage block reuse and bounded conflict repair.
- F4: project georeferencing, WGS84/ECEF/ENU conversion, height datum tracking, spatial bounds and geofences.
- F5: traceable GIS/DEM sources, GeoJSON/KML vector import, topology validation, transactional apply and GeoTIFF DEM terrain grids with NoData masks.
- F6: target-aware route export validation, QGC/WPL capability gates and route package manifests.
- F7: versioned release metadata, Windows packaging path, release documentation and final validation record.

The product version is `1.2.0`. The `.dmproj` project file format remains `1.11`; product version and project schema version are intentionally separate.

## Known limits

- Ground-station import evidence and SITL execution logs are not bundled with v1.2.0. Export files include validation scope metadata so automated validation is not presented as operational flight certification.
- The initial executable target profile is PX4/QGroundControl multirotor. Additional autopilot and ground-station profiles are future work.
- DEM import is functional through the domain/persistence path; a full user-facing DEM import wizard, large rotated raster windowing and richer resampling remain follow-ups.
- Gantt drag-rescheduling, online cross-aircraft synchronisation, stronger cooperative avoidance, full 3D path search, multi-sortie replenishment and scenario comparison are deferred to P1/P2.

## Release decision

v1.2.0 is suitable as a local planning, simulation, GIS/DEM preparation and target-export-validation release. It must not be represented as a certified real-flight control system.
