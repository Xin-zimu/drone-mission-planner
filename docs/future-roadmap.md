# Drone Mission Planner 后续功能详细计划

## 当前基线

当前项目已经完成本地桌面端多无人机任务规划与仿真能力，并已加入 v1.2 环境扩展：

- 2D 地图编辑：基地、无人机、任务点、障碍物、禁飞区、搜索区域。
- A* 路径规划：网格化、避障、安全半径膨胀、路径平滑。
- 多机任务分配：优先级、载荷、电量、返航、安全余量。
- 覆盖规划：多机区域分条、割草式扫描、覆盖率统计。
- 动态仿真：固定步长、播放/暂停/单步、任务完成、电量消耗。
- 故障重规划：无人机失败后保留现场状态并重新分配剩余任务。
- 通信与冲突：多跳通信状态、通信中断记录、简单冲突让行。
- 报告导出：HTML/JSON/CSV 统计报告。
- v1.2 地形/风：程序化山地、高度影响能耗、风向风速影响速度/能耗、2.5D 只读地形视图。

后续目标是把项目从“仿真演示工具”推进到“接近真实无人机任务准备工具”。不做签名安装包；发布方向以源码运行、本地可运行包、普通未签名构建为主。

## M6：2.5D 可用性增强

### 目标

让现有 2.5D 视图从“能看见地形”变成“能辅助判断任务”的视图。

### 功能任务

1. 地形高度图例
   - 在地图角落显示高度颜色范围。
   - 显示最低/最高海拔。
   - 鼠标移动时状态栏显示当前位置地形高度。

2. 风场可视化
   - 在 2D 和 2.5D 视图显示风向箭头。
   - 显示风速、阵风系数。
   - 航线段 tooltip 显示顺风/逆风/侧风影响。

3. 对象高亮
   - 选中无人机、任务、障碍物时，在 2.5D 里同步高亮。
   - 高亮对应航线。
   - 高亮海拔剖面表中的相关行。

4. 标签防重叠
   - 2.5D 标签根据屏幕位置自动偏移。
   - 近距离标签合并或错位。
   - 缩放较小时只显示图标，放大后显示名称。

5. 地形/风参数 UI
   - 增加“环境设置”面板。
   - 可编辑山峰数量、中心、半径、高度、基础海拔。
   - 可编辑风向、风速、阵风系数、启用状态。
   - 修改后自动刷新能耗估算和 2.5D 视图。

### 验收标准

- 打开 `examples/mountain_wind_demo.dmproj` 后能一眼看出山峰高度和风向。
- 选中任意无人机，2.5D 航线和海拔表同步变化。
- UI 修改风速后，任务分配能耗随之变化。
- 2.5D 下不能新增/拖动对象，仍保持只读。

## M7：高度约束进入安全模型

### 目标

让高度从“显示和能耗参数”进入安全约束，避免航线穿过高障碍或低空越过禁飞限制。

### 功能任务

1. 航线高度检查
   - 每条航线段按一定间距采样。
   - 检查飞行高度是否满足 `terrain_altitude + min_clearance`。
   - 对不足 clearance 的航段标记风险。

2. 障碍物高度约束
   - 障碍物保存 `height`。
   - 航线穿过障碍平面投影时，检查飞行高度是否高于障碍物顶部加安全余量。
   - 若高度不足，则路线规划应绕行或抬高。

3. 禁飞区高度约束
   - 禁飞区保存 `ceiling_altitude`。
   - 航线低于禁飞区上限且穿过禁飞区时判定非法。
   - 高于上限时可配置为允许飞越或仍然禁止。

4. 任务目标高度
   - 任务点支持目标高度。
   - 进入任务点前按爬升/下降速率调整。
   - 执行任务时保持目标高度。

5. UI 风险显示
   - 风险航段显示红色或橙色。
   - 属性面板显示具体风险原因。
   - 报告中列出 clearance 风险。

### 验收标准

- 低巡航高度无人机不能直接穿越高障碍物。
- 提高巡航高度后，同一路径可通过高度检查。
- 禁飞区高度规则能在测试里区分“可飞越”和“不可飞越”。
- 报告导出包含高度风险统计。

## M8：增量重规划与补扫

### 目标

故障或任务变更后，只重新规划剩余工作，不重复扫已经覆盖的区域。

### 功能任务

1. 覆盖状态持久化到规划输入
   - 当前仿真已经有覆盖格子状态。
   - 重规划时把已覆盖格子传给 `CoveragePlanner`。
   - 覆盖规划只针对未覆盖目标格子生成扫描任务。

2. 未覆盖区域聚类
   - 把未覆盖格子按连通性分组。
   - 每组生成局部扫描条带。
   - 避免为了少量格子重新扫完整区域。

3. 故障后路径截断
   - 失败无人机的未来路径全部取消。
   - 已经完成的任务保留完成状态。
   - 正在执行但未完成的任务回到 pending。

4. 增量任务分配
   - 只对 pending / assigned 未完成任务重新分配。
   - 分配成本考虑无人机当前位置，不回到初始位置。
   - 保留剩余电量和已飞距离。

5. UI 显示补扫范围
   - 已覆盖区域保留热力图。
   - 未覆盖区域用不同颜色显示。
   - 新生成补扫路径与旧路径区分。

### 验收标准

- 故障后覆盖率能继续增长，不明显重复扫描已覆盖区域。
- 失败无人机不会继续贡献覆盖。
- 重规划前后的电量、时间、覆盖历史不重置。
- `rescue_demo.dmproj` 故障恢复后覆盖率稳定超过目标值。

## M9：真实数据导入

### 目标

让用户能把外部地图、区域、高程和航点数据带入项目。

### 功能任务

1. DEM/CSV 高程导入
   - 支持 CSV 网格：`x,y,elevation`。
   - 支持规则栅格：宽、高、分辨率、海拔矩阵。
   - 暂不做复杂地理投影，先保持本地米制坐标。

2. GeoJSON 导入
   - Polygon 导入为搜索区域或禁飞区。
   - Point 导入为任务点或基地。
   - LineString 可导入为参考路线。

3. KML 导入
   - 支持基础 Polygon / Point。
   - 经站点转换到本地坐标时，需要用户选择原点和比例。

4. 航点 CSV 导入
   - 字段：`id,x,y,z,action,speed,hold_seconds`。
   - 可导入为无人机预设路径。

5. 导入预览
   - 导入前显示对象数量和边界范围。
   - 检查越界、重复 ID、空多边形。
   - 用户确认后写入项目。

### 验收标准

- 能导入一个 CSV 高程文件并生成地形模型。
- 能导入 GeoJSON 多边形作为搜索区域。
- 导入错误给出明确行号或对象 ID。
- 保存后 `.dmproj` 能完整恢复导入数据。

## M11：真实地图底图

### 目标

支持把任务规划叠加到真实地图或用户提供的本地地图图片上。

### 功能任务

1. 本地图片底图
   - 支持 PNG/JPG 导入。
   - 作为地图背景层显示。
   - 可设置透明度、锁定、隐藏。

2. 比例尺校准
   - 用户选择图片上两个点。
   - 输入真实距离。
   - 自动计算像素到米的比例。

3. 坐标原点
   - 用户选择本地坐标原点。
   - 支持 x/y 轴方向设置。
   - 所有对象坐标按米显示。

4. 地图旋转
   - 支持底图旋转角度。
   - 路径规划仍在本地米制坐标中进行。

5. 项目保存
   - `.dmproj` 保存底图路径、比例尺、原点、旋转。
   - 路径优先保存相对路径。

### 验收标准

- 导入一张地图图片后，任务对象能叠加显示。
- 两点校准后，地图距离测量接近用户输入值。
- 重新打开项目后底图和比例尺保持一致。

## M12：真实航线导出

### 目标

把规划结果导出成无人机任务软件能读取的格式。

### 功能任务

1. 通用航点 JSON
   - 导出项目内部标准格式。
   - 包含无人机 ID、航点序列、高度、速度、动作。

2. 通用航点 CSV
   - 字段简单，便于 Excel 或其他工具检查。
   - 每一行一个航点或动作。

3. QGroundControl `.plan`
   - 输出基础 mission items。
   - 支持起飞、航点、悬停、返航。
   - 初期不直接连接飞控。

4. ArduPilot Mission Planner 格式
   - 输出 WPL 文本格式。
   - 支持常见 MAV_CMD。

5. 导出前校验
   - 检查高度、速度、电量、安全风险。
   - 对无法导出的动作给出原因。

### 验收标准

- 一个简单巡检任务能导出 QGroundControl `.plan`。
- 导出文件能被 QGroundControl 打开。
- 导出前若存在未解决风险，UI 明确提示。

## M13：三维航点模型

### 目标

把航线从 `Point(x, y)` 升级到真正的三维航点和动作序列。

### 功能任务

1. 新增 `Waypoint`
   - 字段：`x`, `y`, `altitude`, `altitude_mode`, `speed`, `action`。
   - `altitude_mode` 支持 `MSL` 和 `AGL`。

2. 兼容旧路径
   - 旧 `Point` 路径读取后自动转换为默认高度航点。
   - 保存时使用新 schema。

3. 航点动作
   - `fly_to`
   - `hover`
   - `take_photo`
   - `land`
   - `return_to_launch`

4. 仿真升级
   - 每个航点动作影响状态机。
   - 悬停、拍照、降落有持续时间。
   - 高度变化按爬升/下降速率执行。

5. UI 编辑
   - 航点表可编辑高度、速度、动作。
   - 地图选择航点后显示属性。

### 验收标准

- 旧项目能打开并迁移。
- 新项目能保存三维航点。
- 仿真能执行悬停和拍照动作。
- 航线导出包含高度和动作。

## M14：风险评估

### 目标

从“能规划”升级为“知道哪里危险、为什么危险”。

### 功能任务

1. 电量风险
   - 计算每段后剩余电量。
   - 标记低于安全余量的航段。
   - 考虑逆风、载荷、爬升。

2. 通信风险
   - 根据基地和无人机通信范围计算覆盖区域。
   - 显示可能失联航段。
   - 多机中继时显示链路依赖。

3. 地形风险
   - 标记 clearance 不足航段。
   - 标记大爬升、大下降段。

4. 禁飞/障碍风险
   - 区分水平穿越风险和高度穿越风险。
   - 支持风险严重度。

5. 风险评分
   - 给每条航线总风险分。
   - 分解为电量、通信、地形、空域。

### 验收标准

- UI 能显示每条航线风险分。
- 选中风险段能看到具体原因。
- 报告导出包含风险矩阵。

## M15：任务回放系统

### 目标

支持仿真结束后复盘任务过程，而不只是看最终状态。

### 功能任务

1. 状态记录
   - 每隔固定时间记录无人机位置、电量、高度、状态。
   - 记录任务状态、覆盖率、事件。

2. 时间轴 UI
   - 拖动滑块查看历史状态。
   - 支持播放、暂停、跳到事件。

3. 事件标记
   - 故障、重规划、通信丢失、任务完成显示在时间轴上。

4. 回放导出
   - 导出 JSON 回放数据。
   - 报告中嵌入关键帧。

### 验收标准

- 仿真结束后可拖动时间轴查看任意时刻。
- 点击故障事件能跳到故障发生时间。
- 回放不改变真实仿真结果。

## M16：无人机、电池和任务模板库

### 目标

减少手工输入，把项目参数变得更接近真实设备。

### 功能任务

1. 无人机型号库
   - 名称、最大速度、巡航速度、载荷、通信距离。
   - 默认能耗参数。

2. 电池库
   - 容量、额定电压、可用能量、安全余量。
   - 老化系数。

3. 载荷库
   - 相机、投放箱、传感器。
   - 重量和功耗。

4. 任务模板
   - 巡检。
   - 搜救。
   - 配送。
   - 测绘覆盖。

5. UI 管理
   - 增删改模板。
   - 新建无人机时选择型号。

### 验收标准

- 新建无人机可以从型号库带出默认参数。
- 更换电池型号后能耗余量重新计算。
- 模板数据随项目或全局配置保存。

## M17：高级覆盖规划

### 目标

让覆盖规划适应更复杂的真实区域。

### 功能任务

1. 多边形洞
   - 搜索区域支持内部排除区域。
   - 覆盖统计排除洞内格子。

2. 多区域任务
   - 一个项目内支持多个搜索区域同时规划。
   - 每个区域可以有不同目标覆盖率和优先级。

3. 按优先级覆盖
   - 高优先级区域先覆盖。
   - 电量不足时优先保证关键区域。

4. 补扫规划
   - 只针对未覆盖格子生成路线。
   - 小块未覆盖区域聚类后分配给最近无人机。

5. 方向优化
   - 扫描方向可按区域形状自动选择。
   - 可按风向调整扫描方向，减少逆风长航段。

### 验收标准

- 带洞多边形不会把洞内区域计入目标覆盖。
- 多个搜索区域能同时生成覆盖路线。
- 故障后补扫路径长度明显小于完整重扫。

## M18：协同避碰与中继优化

### 目标

从简单优先级让行升级为更系统的多机协同。

### 功能任务

1. 时空预约表
   - 把航线按时间离散成空间占用。
   - 新航线避开已有预约。

2. 等待点
   - 自动插入等待点。
   - 在窄通道前排队。

3. 通道管制
   - 对狭窄可通行区域设置单向或错峰规则。

4. 中继无人机
   - 支持无人机只负责通信中继。
   - 中继机保持在指定区域或跟随任务队形。

5. 冲突解释
   - 显示冲突对象、预计时间、预计距离、让行原因。

### 验收标准

- 两条交叉路线不会只靠运行时临时等待，而是在规划阶段错峰。
- 中继机能让远端任务保持多跳通信。
- 报告中列出冲突和让行动作。

## M19：可解释规划

### 目标

让用户知道系统为什么这样规划，而不是只看到结果。

### 功能任务

1. 分配解释
   - 每个任务显示候选无人机评分。
   - 显示距离、能耗、风险、载荷、电量因素。

2. 拒绝原因
   - 对每架未选无人机给出具体原因。
   - 例如载荷不足、电量不足、无法安全返航、路径不可达。

3. 规划建议
   - 给失败任务生成可执行建议。
   - 例如增加基地、提高电量、降低覆盖率、调整禁飞区。

4. 成本权重 UI
   - 用户可调整能耗、时间、风险、任务均衡权重。
   - 显示权重调整后的方案变化。

5. 报告解释
   - 导出每个任务的分配依据。

### 验收标准

- 任务分配表能展开查看候选评分。
- 失败任务给出的建议能对应真实约束。
- 修改权重后分配结果可解释。

## 推荐优先级

### 第一优先级

1. M6：2.5D 可用性增强。
2. M7：高度约束进入安全模型。
3. M8：增量重规划与补扫。

原因：这三项直接补强当前 v1.2 的核心能力，改动集中在现有地形、风、覆盖和仿真模块上，风险可控，效果明显。

### 第二优先级

1. M11：真实地图底图。
2. M12：真实航线导出。
3. M13：三维航点模型。

原因：这三项决定项目能否接近真实无人机任务准备流程，但会引入数据格式、坐标、航点动作等更大的结构改动。

### 第三优先级

1. M14：风险评估。
2. M15：任务回放系统。
3. M19：可解释规划。

原因：这些能力提升专业性和可用性，但最好建立在高度约束、真实航点和增量重规划之后。

## 建议开发顺序

1. 先做 M6，快速提升可见效果和操作体验。
2. 再做 M7，把高度/障碍/禁飞区变成真实约束。
3. 接着做 M8，解决故障后重复扫描和补扫问题。
4. 然后做 M11，引入地图底图和比例尺校准。
5. 做 M13，把内部航线升级为三维航点。
6. 在 M13 稳定后做 M12，导出真实任务文件。
7. 最后逐步叠加 M14-M20。
