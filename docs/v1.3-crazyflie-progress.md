# v1.3 Crazyflie Execution Progress

## CF4 Checkpoint

### Completed

- Added bridge-side `CrazyflieAdapter` protocol with a deterministic `SimCrazyflieAdapter` for software execution tests.
- Added bridge-side `MissionExecutor` that runs takeoff, waypoint `go_to` commands and land sequentially from one `ExecutionMission` payload.
- Added waypoint-state and mission-state events for commanded/reached/landed progress.
- Added adapter protection against overlapping commands; a second command while one is active raises instead of being accepted.
- Updated the CF3 protocol server so `backend=sim` can load and execute a mission through the sim adapter, while `backend=hardware` still rejects execution in this phase.

## CF2 Checkpoint

- Added pure-Python frame transforms for `relative_takeoff` / `absolute_local` execution frames with explicit origin translation, yaw rotation and local Z normalization.
- Added `compile_crazyflie_mission()` to compile the authoritative Planner `Drone.waypoints` route into an immutable `ExecutionMission`.
