# v1.3 Crazyflie Execution Progress

## CF1 Checkpoint

### Completed

- Added the pure-Python execution package without ROS, Crazyswarm2, cflib, TCP or UI dependencies.
- Added immutable execution domain models for target profiles, execution waypoints, execution missions, frame calibration, safety limits, robot capabilities and preflight reports.
- Added the first Crazyflie 2.x / Crazyswarm2 single-vehicle target profile with conservative limits and an explicit action whitelist.
- Added execution validation for profile mismatch, unsupported actions, speed overflow, altitude overflow, radius overflow, invalid calibration, empty missions and robot capability gates.
- Added deterministic SHA-256 hashing for the authoritative Planner `Drone.waypoints` route payload.

### Known limitations

- CF1 intentionally does not compile Planner waypoints into execution-frame coordinates; that begins in CF2.
- CF1 intentionally does not implement the Planner/Bridge protocol, ROS 2 bridge, telemetry UI or hardware control.
- Preflight capability inputs are typed domain data only; real robot discovery is deferred to later bridge phases.
